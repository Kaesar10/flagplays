2. Objeto

FlagPlays es una aplicación de dibujo y gestión de jugadas de flag football, de uso gratuito para los equipos de la federación andaluza de fútbol americano. La aplicación se distribuye como aplicación de escritorio para Windows y como aplicación Android, y su código puede solicitarse al titular.
